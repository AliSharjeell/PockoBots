Android preview of Pocket Agent: a local Termux coding agent powered by pi-agent-core, with streaming chat, file editing, Git/shell tools, managed npm development servers, configurable OpenAI/Anthropic connections, API tests, and Microsoft Dev Tunnels controls.

Install `pocket-agent-debug.apk` below, then follow the [Termux setup instructions](https://github.com/AliSharjeell/pocket-agent#install-on-your-phone). The APK requires a running Termux backend; model requests use your configured provider. Android 8+ is required.

Backend integration tests, mobile/desktop browser flows, Android compilation, and Android lint pass in CI. The APK is signed with a development debug key. Physical Android device behavior and authenticated Dev Tunnels still need device testing.
